# CIRCA Website + CMS Login Prototype

Pages: Home, About, Contact, Teacher Login, School Login, Parent Portal Login, CIRCA Academy Login.

Extract the ZIP and open `index.html`. Keep the `css`, `js`, `assets`, and `cms` folders together with the HTML files.

This is a front-end prototype, not the entire CIRCA system. Login forms do not authenticate accounts; the contact form does not send messages; Academy does not yet have an authenticated CMS dashboard or generate real school registration links. Secure backend, account verification, role checks, school isolation, database and audit logs are required before production.
